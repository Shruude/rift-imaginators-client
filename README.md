# Rift Imaginators Client

An unofficial Windows client and launcher for Skylanders Imaginators (Wii U US v0).

## Download and play

1. Open [Releases](https://github.com/Shruude/rift-imaginators-client/releases/latest) and download **Rift-Launcher-0.1.0.zip**.
2. Extract the entire ZIP into its own folder. Run **Rift-Launcher.exe**.
3. In Settings, choose your game's extracted **.rpx** file and your save folder. Install the bundled client, then select **Play**.

The launcher checks this repository for client updates. When a newer version is available, its large Play button becomes **Update**. Your saves and figures stay in separate local folders.

Game files, console fonts, saves, and figure data are not included. This release does not provide online co-op or a bot teammate.

## Included changes

- Keyboard prompts and configurable controls, a denser Rift character library, and mouse-wheel navigation.
- Rift Trainer rewards and ability unlocks.
- Rift Momentum: a direct Kaos boss fight that rewards three consecutive clean hits with health.
- An **Esc Settings** menu with the emulator menu hidden during supported gameplay.

The Esc menu captures input but does not pause the game. This is an early build. Boss entry, combat rewards, and returning to the hub were tested; a full boss victory has not been play-tested.
